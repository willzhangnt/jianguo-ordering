# 建国水产订货系统

客户通过微信打开网页即可在线订货，商家在后台管理订单和商品。

## 快速启动

```bash
pip install -r requirements.txt
python app.py
```

启动后访问：
- **客户订货页面**：http://localhost:5000
- **后台管理页面**：http://localhost:5000/admin

## 后台管理密码

默认密码：`jianguo2026`

修改密码：设置环境变量 `ADMIN_PASSWORD` 后重新启动。

## 微信使用方式

1. 将系统部署到公网服务器（或使用内网穿透工具获取公网地址）。
2. 将订货页面链接发送给客户，客户点击即可打开。
3. 客户选择商品加入购物车，填写姓名电话后提交订单。
4. 商家打开后台管理页面，查看订单并进行处理（确认/送达/取消）。

## 主要功能

### 客户端
- 浏览商品列表（名称、价格、单位、描述）
- 购物车加减数量、一键清空
- 填写姓名、电话、地址、备注后提交订单
- 自动记住客户信息，下次下单免填写

### 后台管理
- 登录/退出
- 今日订单数、待处理数、今日金额、总订单数统计
- 按状态和日期筛选订单
- 订单状态管理（待处理 → 已确认 → 已送达 / 已取消）
- 商品添加、编辑、删除

## 数据存储

使用 SQLite 数据库，文件位于 `data/orders.db`，系统启动时自动创建表和默认商品数据。

## 修改默认商品

默认商品仅在数据库首次创建时写入。如需修改，在后台管理页面的"商品管理"标签页操作。
